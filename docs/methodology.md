# ระเบียบวิธีและนิยามตัวชี้วัด

แหล่งข้อมูลคือ `1.2.1 พืช-อำเภอต่อปี-new.xlsx` โดยใช้ชีตรายพืช 9 ชีตเป็นแหล่งหลัก เนื่องจากชีต `รายละเอียดรวม` ครอบคลุมไม่ครบทุกพืชและทุกปี

## สูตร

- พื้นที่เพาะปลูกรวม = ผลรวม `planted_area_rai` ภายใต้ตัวกรอง
- พื้นที่เก็บเกี่ยวรวม = ผลรวม `harvested_area_rai` ภายใต้ตัวกรอง
- ผลผลิตรวม = ผลรวม `production_ton` ภายใต้ตัวกรอง
- ผลผลิตเฉลี่ยถ่วงน้ำหนัก = ผลผลิตรวม × 1,000 ÷ พื้นที่เก็บเกี่ยวรวม
- อัตราการเก็บเกี่ยว = พื้นที่เก็บเกี่ยวรวม ÷ พื้นที่เพาะปลูกรวม
- YoY = (ค่าปัจจุบัน − ค่าปีก่อน) ÷ |ค่าปีก่อน|

ถ้าปีก่อนหายไปหรือมีค่า 0 ระบบแสดง N/A/— ไม่แสดง 0% และไม่แปลง null เป็น 0

## คุณภาพข้อมูล

`harvested_area_rai > planted_area_rai` เป็น warning ที่ต้องตรวจสอบ ไม่ใช่การแก้ค่าต้นฉบับโดยอัตโนมัติ ข้อมูลรายเดือน 264 ระเบียนมีฟิลด์ตัวเลขหลักว่างทั้งหมดจึงไม่เผยแพร่ใน Dashboard
