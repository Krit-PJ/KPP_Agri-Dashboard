# คู่มือผู้ดูแลระบบ

Dashboard สาธารณะอ่านข้อมูลจริงจาก `Annual_Data` ใน Google Sheets แบบ read-only ปุ่ม “สำหรับเจ้าหน้าที่” เปิดไฟล์ Google Sheet โดยตรงและอาศัยสิทธิ์บัญชี Google ที่กำหนดใน Drive

ระบบหลังบ้านฉบับพร้อมใช้งานอยู่ใน `google-apps-script` เมื่อติดตั้งลงในไฟล์ Sheet แล้ว
ให้เปิดเมนู `ระบบข้อมูลการเกษตร > เปิดระบบเพิ่ม/แก้ไข/ลบข้อมูล` เพื่อใช้ Sidebar
จัดการ `Annual_Data` และ `Monthly_Data`

ขั้นตอนนำเข้าที่กำหนดไว้:

`Upload → Preview/Mapping → Validate → Commit → Review → Publish`

ใช้ Container-bound Apps Script ภายใน Spreadsheet สำหรับเพิ่ม แก้ไข ลบ ตรวจข้อมูลซ้ำ
สำรองข้อมูล และเปลี่ยนสถานะ ห้ามใช้ Frontend สาธารณะเขียนข้อมูลกลับ Sheet โดยตรง

ข้อกำหนดสำคัญ:

- ห้ามเปลี่ยนชื่อหัวคอลัมน์ใน `Annual_Data`
- ใช้ `year_be + crop_code + district_code` เป็น Business Key
- `record_id` ต้องไม่ซ้ำ
- ค่าว่างหมายถึงไม่มีข้อมูล ห้ามแทนด้วยศูนย์
- ตรวจ `Quality_Issues` ก่อนเผยแพร่
- ทำสำรองก่อนการนำเข้าแบบแทนที่หรือการแก้ไขจำนวนมาก

## การลบและการกู้คืน

- ปุ่ม `เก็บ` เปลี่ยนสถานะเป็น `archived` จึงกู้คืนได้และไม่แสดงบน Dashboard
- ปุ่ม `ลบ` ลบแถวจริงหลังพิมพ์รหัสระเบียนยืนยัน
- ก่อนแก้ไข เก็บถาวร หรือลบ ระบบบันทึกข้อมูลเดิมใน `_Row_Backups`
- ทุกการกระทำบันทึกผู้ใช้ เวลา และรายละเอียดใน `_Audit_Log`
