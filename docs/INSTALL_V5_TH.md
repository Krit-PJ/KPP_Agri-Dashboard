# คู่มือติดตั้ง KPP Agri Dashboard v5.1.0

## 1. เผยแพร่เว็บไซต์

Push โค้ดทั้งหมดขึ้น `main` แล้วตรวจ GitHub Actions งาน `Deploy GitHub Pages` จนเป็นสีเขียว หน้าเว็บจะอ่าน `Registration_Data` จาก Google Sheet เดียวกับข้อมูลเอกภาพ และกลับไปใช้ snapshot เมื่อ Sheet ยังไม่มีข้อมูลหรืออ่านไม่ได้

Environment ที่ตั้งเพิ่มได้ในขั้น build:

- `VITE_GOOGLE_SHEET_ID` — ID ของ Google Sheet สำหรับ Dashboard
- `VITE_REGISTRATION_SHEET_TAB` — ค่าเริ่มต้น `Registration_Data`
- `VITE_ADMIN_SHEET_URL` — URL ของ Google Sheet ที่ติดตั้งระบบ Admin ปุ่ม Admin บนหน้าแรกจะเปิด URL นี้

Google Sheet ต้องเปิดสิทธิ์อ่านแบบ “Anyone with the link / Viewer” เฉพาะชีตข้อมูลที่ใช้กับเว็บสาธารณะ และไม่ควรเก็บข้อมูลส่วนบุคคลในตารางเผยแพร่

## 2. ติดตั้งระบบ Admin

1. เปิด Google Sheet หลัก → **ส่วนขยาย → Apps Script**
2. คัดลอก `Code.gs`, `AdminRegistration.gs` และ `Sidebar.html` เข้าโครงการ
3. บันทึกและรัน `installSystem()` หนึ่งครั้ง จากนั้นอนุญาตสิทธิ์ตามหน้าจอ Google
4. เปิด Sheet ใหม่ → เมนู **ระบบข้อมูลการเกษตร → เปิดระบบเพิ่ม/แก้ไข/ลบข้อมูล**
5. ในชีตซ่อน `_Admin_Users` เพิ่มอีเมลผู้ดูแลหลักในคอลัมน์ `email` และค่า `owner` ในคอลัมน์ `role`

หน้าแรกมีการ์ด **ระบบบริหารข้อมูล** และปุ่ม **เข้าสู่ระบบ Admin** ซึ่งเปิด Google Sheet นี้โดยตรง การเพิ่ม/แก้ไขข้อมูลยังทำภายใน Sidebar ของ Google Sheets เพื่อให้ Google ยืนยันตัวตนและบันทึก Audit log ได้ครบถ้วน

ระบบใช้บัญชี Google ที่กำลังเข้าสู่ระบบ ไม่ใช้ username/password ใน JavaScript หรือ GitHub Pages ผู้ช่วยดูแลกด “ขอสิทธิ์ผู้ช่วยดูแล” แล้วผู้ดูแลหลักอนุมัติผ่าน `decideAdminRequest({email:'...', approve:true})`

## 3. นำเข้าข้อมูล

- **ข้อมูลเอกภาพ**: CSV ต้องมีหัวคอลัมน์ตรงกับ `Annual_Data`
- **ข้อมูลผลการขึ้นทะเบียน**: ส่งออกไฟล์ Excel เป็น CSV UTF-8 ก่อน แล้วเลือกชนิดพืชและประเภท “พื้นที่ปลูก/พื้นที่เก็บเกี่ยว” ทุกครั้ง ระบบอ่านแถวระดับอำเภอรหัส `62-01`–`62-11`

ทุกการนำเข้ามี Batch ID, เวลา, อีเมลผู้นำเข้า และ Audit log หากชนิดพืชหรือประเภทพื้นที่ไม่ถูกเลือก ระบบจะไม่เขียนข้อมูล

## 4. ข้อสังเกตไฟล์แนบ

ไฟล์ต้นฉบับไม่มีคอลัมน์ชนิดพืชและประเภทพื้นที่ ชุดสำรองบนเว็บจึงกำหนดเป็น “ข้าวนาปี / พื้นที่ปลูก” ตามค่าตั้งต้นสำหรับการนำเข้าครั้งแรก ควรตรวจยืนยันกับเจ้าของข้อมูลก่อนเผยแพร่เป็นข้อมูลทางการ
